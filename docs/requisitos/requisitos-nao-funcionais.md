# Requisitos não funcionais

O legado cita rapidez e facilidade para integrar novos equipamentos, mas ainda sem métricas. A equipe deve transformar essas intenções em critérios verificáveis quando a atividade solicitar.

Exemplos de aspectos a detalhar: desempenho, disponibilidade, confiabilidade das integrações, segurança de pagamento e manutenibilidade.
