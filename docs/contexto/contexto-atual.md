# Contexto atual — SmartPark

O SmartPark gerencia vagas, veículos, reservas, entrada e saída, cobrança e integração com equipamentos externos de um estacionamento inteligente.

## Atores
- motorista;
- operador do estacionamento;
- administrador.

## Sistemas externos
- sensores de ocupação;
- gateway de pagamento;
- controle de cancelas;
- serviço de notificações.

Consulte também `stakeholders.md`, `sistemas-externos.md` e os requisitos em `../requisitos/`.
